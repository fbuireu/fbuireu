# Support

This repository renders the profile at [github.com/fbuireu](https://github.com/fbuireu). There is no software
to support here, so this page exists to say where the few things that can go wrong actually go.

## Most of what you see is generated

The activity list, the WakaTime stats, the metrics image and the snake animation are written by scheduled
workflows between the markers in each README. **A stale or missing section is a workflow that failed**, not a
file someone forgot to edit: the badges in the *Debug* section of the profile link to the runs, and the failed
one is usually the answer.

Editing the content between those markers by hand achieves nothing: the next scheduled run overwrites it.

## If something is broken

Open a [bug report](https://github.com/fbuireu/fbuireu/issues/new?template=bug_report.yml): a dead link, an
image that never loads, a section that has not refreshed in weeks. Say which of the four Editions you were
reading, since the English one is the only one GitHub renders on the profile and the other three drift more
easily.

## Vulnerabilities

Privately, through the [security policy](https://github.com/fbuireu/fbuireu/security/policy), never as an
issue. The realistic surface here is the workflows and the third-party actions they call, and
[SECURITY.md](./SECURITY.md) covers it.
